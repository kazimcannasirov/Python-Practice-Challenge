# Python-Practice-Challenge
Given the following list:

numbers = [15, 4, 9, 20, 7, 20, 3, 8, 11, 4, 6]

Create a new list containing only the odd numbers.

Requirements
1.The new list must contain only odd numbers.
2.Duplicate numbers must not be included.
3.Preserve the original order of the numbers.
4.Use a for loop.
5.Do not use:
set()
sum()
max()
min()

After creating the new list, calculate and display:

1.The list of unique odd numbers.
2.The number of elements in the new list.
3.The sum of all elements in the new list.
4.The largest element in the new list.
